# AI Task Management System

## Features

* JWT Authentication
* Role-Based Dashboards
* Project & Task Management
* Real-Time Task Updates
* Dashboard Analytics
* AI Chatbot
* PDF Chat Export
* Dark/Light Mode

## Tech Stack

### Frontend

* React
* Bootstrap
* Chart.js

### Backend

* Django
* Django REST Framework
* Django Channels

## Run Backend


cd backend
python manage.py runserver


## Run Frontend


cd frontend
npm run dev
